# 부산항 타부두 환적(ITT) 이동시간 분석

스마트항만·물류 데이터 분석 팀프로젝트 (4주)

## 프로젝트 질문
환적에 걸리는 시간을 공정별로 나눴을 때, 비효율 가능성이 높은 구간은 어디인가?
터미널 내부 체류와 터미널 간 이동을 구분해서 분석합니다.

## 분석 흐름
선박 양하 → HJNC 체류 → Gate Out → 터미널 간 이동(ITT) → 다른 터미널 Gate In → 이후 체류

## 분석 방법
- 동일 컨테이너의 반출(OUT) → 반입(IN) 기록 매칭
- 공정별 소요시간의 평균·중앙값·P90/P95 비교
- 반복적으로 오래 걸리는 구간 식별
- 체류시간이 길다고 바로 비효율로 판단하지 않고, 계획된 대기와 개선 가능한 대기를 구분

## 일정
| 주차 | 내용 |
|---|---|
| 1주차 | 데이터 정의·확보, 컬럼 정의서 |
| 2주차 | 전처리, OUT→IN 매칭, 샘플 검증 |
| 3주차 | 경로·시기별 통계, 확장 분석 |
| 4주차 | 해석, 개선안, 발표 |
