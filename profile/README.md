## 프로젝트 소개

부산 신항의 환적 컨테이너가 야드에 머무는 시간을 분석하고, **연결선 스케줄 조정**과 **선석 통합운영**의 효과를 시뮬레이션으로 비교한 프로젝트입니다.

개별 선박의 작업시간뿐 아니라 컨테이너를 내린 모선과 다시 싣는 연결선 사이의 일정에 주목합니다. 체류시간 감소 효과와 함께 다른 선박에 발생하는 접안 지연을 검토해 운영 개선 방향을 제안합니다.

| 항목 | 내용 |
| :--- | :--- |
| 프로젝트 목적 | 환적 야드 체류시간 저감과 선석 운영 개선 방안 검토 |
| 분석 기간 | 2025년 |
| 환적 분석 대상 | 동원(DGT)·한진(HJNC) 자부두 및 DGT ↔ HJNC 타부두 환적 |
| 선석 운영 범위 | 부산 신항 7개 터미널: BCT, BNCT, DGT, HJNC, HPNT, PNC, PNIT |
| 주요 데이터 | 컨테이너 출입·환적 이력, 선석배정현황, PORT-MIS 입출항 자료, 선박 제원 |

### 개선 제안의 출발점

[개선 제안서](https://github.com/busan-itt/Project-Proposal)는 **선석 공유로 선박 대기시간을 줄이면 모선·연결선 연계가 빨라져 환적 야드 체류시간도 줄어드는지**를 검증하는 방안을 제시합니다. 기존 운영·인접 터미널 공유·신항 전체 통합을 동일 조건에서 비교하고, 선박 대기시간·야드 체류시간·터미널별 부하율로 효과와 부작용을 평가하도록 설계했습니다.

후속 시뮬레이션에서는 연결선 일정의 선별 조정이 체류 저감의 핵심이고, 선석 공유는 다른 선박의 접안 지연을 완화하는 지원 수단이라는 결과를 얻었습니다. 아래 핵심 결과는 이 최종 시뮬레이션을 기준으로 정리했습니다.

## 분석 및 검증 방법

1. **환적 과정 분석** — 자부두·타부두 환적 타임라인을 정리하고, 공정별 소요시간과 야드 체류시간을 비교합니다.
2. **선박·컨테이너 연결** — 컨테이너 이력을 모선·연결선의 접안 일정과 결합해 연결선 간격과 체류 구조를 살펴봅니다.
3. **운영 시나리오 비교** — 선박 길이, 연속 안벽 공간과 시간대별 점유를 반영해 접안을 배정합니다.
4. **연결선 일정 조정** — 연결선의 도착을 앞당기는 전체 조정과 선별 조정을 비교합니다. 선별 조정은 실리는 환적 컨테이너 수가 내리는 수보다 많은 연결선을 대상으로 합니다.
5. **결과 검증** — 반복 시뮬레이션, 부트스트랩 불확실성 구간, 상·하반기 분리 검증과 머신러닝 기반 입력 보완으로 결과의 안정성을 확인합니다.

| 시나리오 | 선석 운영 방식 |
| :---: | :--- |
| **A** | 기존 터미널별 운영 |
| **B** | 인접 터미널 간 선석 공유 |
| **C** | 신항 전체 선석 통합운영 |

**주요 비교 지표:** 평균 야드 체류시간 · 야드 체류 감소율 · 다른 선박의 평균 접안 지연 · 요청 대비 실제 일정 조정 실현율

## 핵심 결과

- **체류시간 개선의 핵심은 연결선 일정 조정입니다.** 분석 대상에서는 체류시간의 대부분이 다음 연결선을 기다리는 구간에 해당했습니다.
- **전체 조정보다 선별 조정이 효율적이었습니다.** 같은 선박이 모선 역할도 하기 때문에, 모든 연결선을 앞당기면 일부 컨테이너의 체류시간은 오히려 늘어날 수 있습니다.
- **선석 공유는 일정 조정을 지원합니다.** A/B/C 간 체류 감소율 차이는 크지 않았지만, 선석 공유는 다른 선박의 접안 지연을 줄이고 요청한 일정 조정의 실현을 돕는 역할을 했습니다.

### 대표 시뮬레이션 결과

| 연결선 선별 조정 조건 | 평균 야드 체류 감소율 | 95% 불확실성 구간 |
| :--- | :---: | :---: |
| 도착 48시간 앞당김 요청 | 약 **10.5%** | 약 8.0~13.1% |
| 도착 96시간 앞당김 요청 | 약 **16.8%** | 약 12.9~20.7% |

감소율은 시나리오 A의 기준 평균 야드 체류시간 대비 값입니다. 조정 후에도 최소 연결 간격 24시간을 유지하며, 요청한 앞당김 시간과 실제 실현 시간은 다를 수 있습니다.

> 위 수치는 실제 운영에서 관측한 개선 실적이 아닌 **시뮬레이션 추정치**입니다. 연결선 일정 변화가 해당 컨테이너의 반출 시각에 같은 만큼 반영된다는 가정을 사용했습니다. 기상·도선·예선·크레인 등 실제 지연 요인과 선사의 일정 변경 가능성을 모두 반영하지는 못했습니다. 지표 정의와 조건은 [최종 시뮬레이션](https://github.com/busan-itt/simulation/blob/main/최종%20시뮬레이션.ipynb)에서 확인할 수 있습니다.
