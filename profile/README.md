부산항 타부두 환적 병목 분석 및 운영 효율화 시나리오 제안

컨테이너 이동 이력 기반 자부두·타부두 환적 비교와 개선효과 분석

스마트항만·물류 데이터 분석 팀프로젝트 (4주)

추진 배경

부산항은 국내 최대 컨테이너 항만이자 국제 환적 거점이며, 환적화물이 물동량에서 높은 비중을 차지합니다. 환적항은 여러 항로를 연결하는 중간 거점이므로, 불필요한 이동과 대기시간을 줄이고 선박 간 연결을 안정적으로 유지하는 것이 경쟁력의 핵심입니다.

자부두 환적: 입항 → 양하 → Yard 체류 → 적하 → 출항
타부두 환적(ITT): 입항 → 양하 → 출발 터미널 Yard 체류 → Gate Out → 트럭 운송 → Gate In → 도착 터미널 Yard 체류 → 적하 → 출항

타부두 환적에는 Gate Out, 육상운송, Gate In 공정이 추가로 발생합니다. 신항에서는 선사 얼라이언스의 대규모 물량을 한 터미널이 모두 수용하기 어려울 때 물량이 다른 터미널로 분산되며 ITT가 발생합니다.

문제 정의

부산항의 타부두 환적은 자부두 환적보다 추가적인 이동과 반출입 공정을 필요로 한다. 실제 추가시간은 얼마나 발생하며, 어느 공정에서 병목 가능성이 나타나는가? 해당 병목을 줄이기 위한 운영방식을 적용하면 어느 정도의 개선효과를 기대할 수 있는가?

STEP 1. 현재 ITT 병목 진단: 실제 컨테이너 이력으로 리드타임과 병목 후보 파악
STEP 2. 개선 시나리오 검증: 세 가지 운영 개선 시나리오를 과거 데이터로 검증
목표

HJNC, DGT, BPT의 컨테이너 이동 이력을 연결해 환적 과정을 공정별로 분해하고, 평균·중앙값·P90·P95 리드타임으로 반복적 장시간 구간(병목 후보)을 식별합니다.

구분	경로
자부두 환적 (기준선)	HJNC → HJNC, DGT → DGT
타부두 환적	HJNC ↔ DGT, HJNC ↔ BPT, DGT ↔ BPT

BPT → BPT는 상세 작업이력 확보의 한계로 자부두 비교에서 제외합니다.
